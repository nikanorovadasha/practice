# Задание №2

## Описание
Реализация программы для работы с парком машин: обработка массивов, коллекций, сравнение объектов и анализ данных с использованием Stream API.

## Проект демонстрирует работу с:
- массивами
- коллекциями (List, Set)
- пользовательскими классами
- equals / hashCode
- Comparable
- Stream API

# Задание №1

## Описание
Работа с массивом годов выпуска автомобилей (50 случайных значений от 2000 до 2025).

## Реализация
- Создание массива `int[] carYears`
- Заполнение случайными значениями через `Random`
- Фильтрация значений > 2015
- Вычисление среднего возраста автомобилей

## Особенности
- Используется генерация случайных чисел
- Расчёт среднего возраста через сумму всех элементов

# Задание №2

## Описание
Работа со списком моделей автомобилей с дубликатами.

## Основные операции
| Операция | Реализация |
|----------|------------|
| Удаление дубликатов | `LinkedHashSet` |
| Сортировка | `Comparator.reverseOrder()` |
| Вывод | цикл `for` |
| Замена Tesla | `contains("Tesla") → ELECTRO_CAR` |
| Сохранение результата | `Set<String>` |

## Особенности
- Используется `Set` для удаления дубликатов
- Используется `List` для сортировки

# Задание №3

## Описание
Класс `Car` с переопределением `equals`, `hashCode` и реализацией `Comparable`.

## Поля класса Car
- VIN
- model
- manufacturer
- year
- mileage
- price

## Реализованные методы

| Метод | Описание |
|------|----------|
| `equals()` | сравнение объектов только по VIN |
| `hashCode()` | хеширование по VIN |
| `compareTo()` | сортировка по году выпуска (от новых к старым) |
| `toString()` | вывод информации об объекте |

# Задание №4

## Описание
Анализ списка автомобилей с использованием Stream API.

## Операции Stream API

| Операция | Реализация |
|----------|------------|
| Фильтрация | `filter(mileage < 50000)` |
| Сортировка | `sorted(price desc)` |
| Топ-3 | `limit(3)` |
| Средний пробег | `mapToInt().average()` |
| Группировка | `groupingBy(manufacturer)` |

## Используемые методы Stream
- filter
- sorted
- limit
- mapToInt
- average
- collect
- groupingBy
