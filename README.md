# Задание №1

## Описание
Реализация класса `BankAccount` для управления банковским счетом.

## Основные методы
| Метод | Описание |
|-------|----------|
| `deposit(int amount)` | Пополнение счета |
| `withdraw(int amount)` | Снятие средств |
| `transfer(BankAccount other, int amount)` | Перевод на другой счет |
| `setBlocked(boolean blocked)` | Блокировка / разблокировка |

## Геттеры и сеттеры
### Добавлены:
| Метод | Назначение |
|-------|------------|
| `getAccountHolderName()` | Получить имя владельца |
| `getBalance()` | Получить баланс |
| `getOpeningDate()` | Получить дату открытия |
| `isBlocked()` | Проверить статус блокировки |
| `getNumber()` | Получить номер счета |
| `setAccountHolderName(String name)` | Изменить имя (на случай ошибки) |
| `setBlocked(boolean blocked)` | Заблокировать/разблокировать счет |

### Не добавлены:
| Метод | Почему? |
|-------|---------|
| `setBalance(int amount)` | Баланс меняется только через `deposit()` и `withdraw()` – защита от некорректного изменения |
| `setOpeningDate(LocalDateTime date)` | Дата открытия не меняется за всё время существования счета |
| `setNumber(String number)` | Номер генерируется один раз в конструкторе |

## Переопределенные методы
| Метод | Назначение |
|-------|------------|
| `toString()` | Вывод информации о счете в читаемом виде |
| `equals(Object obj)` | Сравнение счетов по номеру |
| `hashCode()` | Хеш для корректной работы с коллекциями |

## Особенности
-  Генерация уникального 8-значного номера счета
- Защита от операций с заблокированным счетом
- Нельзя снять больше, чем есть на балансе
